## 复现

在项目根目录：

```
python3 -m http.server 8090
```

另开终端：

```
node tests/core.cjs
python3 tests/browser.py
python3 tests/continuous.py
```

Python 浏览器测试需要 Playwright 与系统 Chromium（默认 /usr/bin/chromium）。WebKit 环境准备好后可用 `BROWSER=webkit python3 tests/browser.py`，届时再记录结果。JavaScript 核心测试只依赖 Node。网页运行不依赖这些开发工具。

## iPad Safari 真机清单

1. 部署 HTTPS 网站，记录机型、iPadOS/Safari 版本；横屏访问。页面不自动发声。
2. 点击原创测试音轨，再播放；观察启动、曲线、隧道、网络、结尾五幕，确认非静态占位。
3. 在每幕暂停 3 秒，画面、光标与时间均应停住，再继续。
4. 暂停时跳到 12、20、28 秒，核对场景；往返跳转 10 次，基本几何应一致。
5. 播放中用手指拖进度条，放开后恢复；暂停中拖动后保持暂停。试听 ±5 秒与重播。
6. 选择自己的有权音频，确认播放/暂停；检查 Safari 网络面板无上传。测试 MP3、AAC、WAV 各一份。
7. 切换 3 种网格、30/24 FPS；观察帧率变化不能改变动作实际时长。精细模式不稳时手动降低网格。
8. 正负偏移与章节跳转核对；关掉响应应仍有完整五幕且音频继续。
9. 横竖屏往返、开关折叠设置、沉浸模式、尝试全屏；所有关键内容完整，无横向溢出，按钮能用手指操作。
10. 完整播放 30 秒，记录开头、结尾声画延迟；后台/锁屏再返回，动画应跟随音频实际位置，若系统暂停音频则动画也保持。
11. 播放结束应停止，再播放从头开始。没有真机测试前，不能保证具体机型上的稳定帧率或声画延迟。
