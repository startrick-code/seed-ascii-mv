# 第一阶段实现说明

采用用户指定的五幕 30 秒方案；直接复用旧播放器可工作的部分，在独立目录增量实现。场景函数输出同样的 Grid，避免重建控制系统。Canvas 只以 fillText 绘制主要画面，fillRect 仅用于黑色清屏；没有视频、图像序列或字体依赖。

数学结构使用参数曲线、逆深度透视、规律节点相位与固定哈希。所有转场由当前时间独立重建。director.js 集中描述场景、起止、转场、视觉参数和关键时刻；更复杂的编辑器不是第一阶段目标。

复用的 Grid 继续处理中文双格，新增第三个 cell 项作为透明度。每次重绘创建场景网格，不跨帧积累粒子；因此任意 seek、暂停和降帧均不会改变动作时长。音频特征只作用于轻微亮度层，不改变相机路径与场景选择。UI 默认折叠高级参数和调试信息，保持黑底终端构图优先。
