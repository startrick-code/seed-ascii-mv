# SEED — 30 秒原创 ASCII 音乐短片 / Phase 1

基于附件 ascii-ipad 增量开发。保留 Grid、音频元素主时钟、本地文件加载、暂停、seek、偏移和基础触控布局；替换旧校准图案及原作时间锚点，新增五幕原创导演、数学场景、真实 FFT 与沉浸模式。无需构建、后端或 CDN。未部署 GitHub 远程。

## 运行

将本目录部署为静态网站；本机预览可执行 `python3 -m http.server 8090`，打开 `http://localhost:8090`。Python 仅为可选静态服务器，网页运行没有 Python 依赖。

在 iPad Safari 横屏打开 HTTP/HTTPS 网站，点击“原创测试音轨”，再点“播放”。测试音轨由 JavaScript 现场合成 30 秒琶音、低音脉冲及持续音，是原创测试音乐，不是 Mili 原曲。也可加载自己有权使用的 MP3/AAC/WAV，文件只以本地 Blob URL 读取，不上传、不保存。静态 HTML 的 Files 快速预览不是完整 Safari 网站，不保证脚本执行。

控制栏可播放/暂停、重播、±5 秒、拖动进度。拖动时临时暂停，结束后恢复原播放状态。折叠设置包含五幕跳转、三档网格、30/24 FPS、动画偏移、音频响应开关和调试信息。正偏移使整个动画提前，章节 seek 会反向扣除偏移。正常观影默认不显示场景名和 FPS；“沉浸模式”隐藏页头和控制栏，右下角可恢复。全屏不受支持时显示提示，仍可正常观影。

固定为 30 秒预览；长音频在 30 秒停止，短音频在实际结尾停止。不支持本阶段之外的歌曲内容。未来若加可选全曲模式，需同步扩展导演时间轴，不能仅放开音频限制。

## 五幕与实际配置

编辑 `director.js` 的 timeline。时间为音频 currentTime + 用户偏移，所有几何骨架直接由绝对时间计算。

| 时间 | 场景 | 实现 |
|---|---|---|
| 0–5 | SYSTEM BOOT | 原创终端逐字指令、闪烁光标、确定性字符粒子向计算核心聚集 |
| 5–11 | MATHEMATICAL CREATION | 核心向外扩展为坐标轴、三条相位正弦曲线和旋转参数曲线 |
| 11–18 | DATA DIMENSION | 前进与轻微旋转的透视字符框架，深度衰减，局部亮度受音量影响 |
| 18–25 | EMERGENT LIFE | 84 个规律运动节点、三类连接、沿节点相位传播的波前，汇聚为五重种子与分枝 |
| 25–30 | CONSCIOUSNESS | 确定性错位、网络碎片收束、文字逐步形成 AWAITING INPUT_、闪烁与渐暗 |

前四幕在结束前分别用 .65、.8、.8、.8 秒进行字符层溶解；同时下一幕以负局部时间提前展开。转场在同一网格内按固定哈希选择字符并衰减旧层，不以上一帧状态累积。第五幕最后 .75 秒淡出，30 秒黑场为有意结尾。

## 源码模块

- `app.js`：复用并扩展播放器、主循环、30 秒限制、原创音轨合成、DPR/尺寸、沉浸与设置。
- `core.js`：原 Grid 与中英文格宽处理，30 秒时间钳位。移除校准图案和假频带。
- `geometry.js`：插值、平滑、固定哈希、旋转、投影及字符线段。
- `scenes.js`：五幕完整独立函数，返回字符图层，未使用视频、整幅位图或几何填充代替 ASCII。
- `director.js`：五幕时间、参数、关键时间与转场。keys 是便于后续编辑的关键时刻记录；当前动作在场景内用绝对时间插值，尚不是通用关键帧编辑器。
- `audio-analysis.js`：Web Audio 生命周期、FFT 和 RMS，独立于导演时间轴。
- `style.css` / `index.html`：安全区、16:9、折叠设置与触控 UI。
- `tests/`：核心、交互及连续播放可复现测试。`docs/scene-*.png`：真实 Chromium 网页运行截图，非概念图。

## 音频与响应

HTMLAudioElement.currentTime 是唯一动画主时钟；rAF 只调度绘图，performance 时间仅用于限帧/FPS。暂停和缓冲不推进场景；回到前台重新读取音频时间，不补跑模拟。

用户点击播放时创建/恢复 AudioContext；先确认运行，再接入媒体源。音频源直接连接 destination，分析器为旁路，即使分析器创建失败仍保留声音路径。1024 点 FFT 分析低于约 220Hz 的频带，同时计算波形 RMS。当前主要使用 RMS 轻微调节整体亮度与隧道亮度；bass 特征保留给后续扩展，未用其决定分镜。关闭响应或分析不可用时使用零特征，五幕仍完整。FFT/RMS 是实时音频特征，**不是人工校准鼓点**。

实时分析值随解码和时间窗不同，同一时间的细微亮度未必完全相同；几何骨架、场景与故障位置确定。暂停冻结采样，跳转时清零上一位置的特征。未提供实际歌曲，故没有完成 Mili 原曲的精确节拍同步。

## iPad 与性能

默认 100×36，128×44 为精细，80×30 为性能模式；Canvas 完整放入可用空间并保持 16:9，DPR 上限 2。目标 30 FPS，可手动选 24 FPS 或较小网格；不自动更改时间或动画速度。FPS 统计实际重绘，暂停时接近 0 属正常。尚未测得真实 iPad 性能，不提供无证据的帧率保证。

所有主要按钮至少 44px；折叠设置不覆盖画面。系统等宽字体，中文占两格；复杂组合文字、emoji 不保证终端级排版。本片主体使用 ASCII。

## 部署 GitHub Pages

把本目录内容（index.html 位于根）提交到自己的仓库，在 Settings → Pages 选择 Deploy from a branch → main / root，保存后打开给出的地址。无需 npm 或构建。所有资源相对路径，支持仓库子目录；`.nojekyll` 已保留。不要把无授权音频加入公开仓库。本次未进行任何远程部署。
