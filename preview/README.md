基于 GitHub `startrick-code/seed-ascii-mv` 提交 `327f99510453a5e11caabff3fce9af8ac4b18ba6`。未向 GitHub 写入、没有覆盖线上 Pages。本包不含原曲、歌词或第三方字体。

## 运行与试听

用 HTTP/HTTPS 静态服务器打开 index.html，例如 `python3 -m http.server 8094` 后访问 localhost:8094。iPad 从可访问的 HTTPS/局域网地址打开。点击本地音频选择器，选择本次提供的 MP3，再点击播放。识别到相同文件后状态显示“已识别校准音轨”，加载对应分析包络；其他音乐只使用实时频段响应，分镜仍按本次文件编排。没有歌曲时，点击原创测试音轨可验证完整五幕。

`standalone.html` 是由相同源码生成的单文件版本，内嵌 JSON/CSS/JS，仍不含音乐；可下载后在支持执行脚本的浏览器环境打开。iPad Files 快速预览不保证运行 HTML。index.html 需要 HTTP/HTTPS 加载 JSON，不能直接 file:// fetch。

播放、暂停、±5 秒、拖动、场景选择、正负偏移、三档网格、24/30 FPS、沉浸和全屏回退继续保留。所有场景始终用 audio.currentTime + offset；不积分模拟时间。固定 30 秒预览，不开发全曲。正偏移让动画及其编排包络提前，实时 FFT 始终是正在发声的音频，偏移不改变声音。

## 实测音乐结构及分镜

实测文件总长 **214.360816 秒**。分析 0–30 秒单声道信号，非主观听感标注。

| 秒 | 分镜 | 依据及表现 |
|---|---|---|
| 0–5.887 | SYSTEM BOOT | 开头约 5.9 秒近静音：稀疏字符、终端初始化和逐步聚核 |
| 5.887–12.013 | MATHEMATICAL CREATION | 首次明显起音触发三重字符波前；核心展开成多层曲线，频段调节形状及密度 |
| 12.013–20.773 | DATA DIMENSION | 从起音候选中选的导演分组点，非已确认乐句边界；进入透视隧道，低频改变截面及前进位移，高频增加细节 |
| 20.773–26.111 | EMERGENT LIFE | 明显起音 + 持续能量提升；大型三层波前打开网络，连接密度和形变响应中频 |
| 26.111–30 | CONSCIOUSNESS | 为样片收尾选择的起音候选，非原曲结尾；碎片重组等待输入并渐隐 |

6–19 秒逐秒平均 RMS 大多约 .28–.32；21–29 秒约 .38–.43；20.773 秒附近的持续变化支持用户指出的约 20.8 秒转折。起音候选常见约 .46 秒间隔，但未人工确认 BPM、拍号或每一个鼓点。这里是首次依据实测信号编排的样片，不声称逐拍人工校准完成。

## 可编辑 JSON

`music-timeline.json` 包含音频 SHA-256、总长、分析方法、五幕起止/转场/参数、导演事件、自动起音候选，以及每 100ms 的 RMS/低中高频归一化包络（301 行）。这不是原音频或完整 FFT，也不能恢复音乐。scenes 与 events 可直接编辑；候选 onsetCandidates 不会自动全部触发分镜。导演事件表是人工工程选择，尚无听觉标注。

本机识别用 SHA-256，不上传文件/指纹。HTTPS 或 localhost 提供 Web Crypto；不支持时仍使用实时 FFT。换音频立刻关闭旧包络，异步识别有竞态保护，防止将旧文件分析误用于新文件。测试音轨不加载原曲包络。

## 修复点

旧版只读 bass/rms，bass 实际没进入多数场景计算，rms 主要是 6% 以内亮度修饰，因而换曲几乎不改变画面。现在三个频段进入共享字符坐标变换：尺度、径向扭转、波形位移；曲线有相位/幅度变形和多层参数轨迹；隧道截面/位移及数字密度改变；网络连接数改变。音量与亮度只是补充。没有用随机闪烁冒充音乐响应。

- `audio-analysis.js`：2048 点 AnalyserNode；35–220 / 220–2200 / 2200–9000Hz 特征及 RMS。
- `scenes.js`：保留五幕模型，增加共享几何响应和层次，采用纯函数、限定字符线采样上限。
- `director.js`：读取 JSON，匹配音轨时使用可跳转包络，叠加小幅实时特征；编排大转场。
- `app.js`：本地文件识别与 JSON 就绪处理、从 JSON 生成章节菜单，基础控制路径保留。
- `standalone.html`：同版本单文件产物；`tools/build-standalone.py` 可重新生成。

关闭“音频响应”将关闭能量/频段形变；导演时间轴和首次进入/转折的编排波前仍保留。暂停冻结实时分析；跳转清除上一位置实时特征，对匹配音轨立即查包络，因此无需先播放才能得到相应音乐状态。实时层受解码窗影响会有微小差异，不能承诺播放和暂停直接 seek 的所有像素完全相等。
